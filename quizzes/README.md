# 學院題庫格式（format 1）

每個學科一個 JSON 檔，檔名＝`<id>.json`，並把檔名加進 `quizzes/index.json` 的 `subjects`。
學院頁會依 `index.json` 的順序顯示學科卡片。格式由 `js/quiz.js` 的 `validateSubject` 檢查，
格式錯誤的題庫在瀏覽器會被略過並在主控台報錯；`node tests/quiz.test.mjs` 會驗證所有題庫。

```jsonc
{
  "format": 1,                 // 格式版本，固定 1
  "id": "science",             // 小寫英數與 -；也是貓咪屬性的 key（petData.stats[id]）
  "name": "生活自然",
  "icon": "🔬",
  "color": "#8b5cf6",          // 主色 #rrggbb
  "bgLight": "#f5f3ff",        // 淺底色 #rrggbb
  "statName": "科學",          // 測驗後成長的能力名稱
  "desc": "學科卡片上的說明",
  "roundSize": 3,              // 每次測驗抽幾題（≤ 該程度題數）
  "questions": [
    {
      "id": "science-g5-01",    // 題庫內唯一，建議 <學科>-g<年級>-<編號>
      "grade": 5,               // 程度（年級），見下表
      "term": "5-1",            // 冊次：年級＋學期（5-1 = 五上）；沒標＝該年級上下學期都可出
      "versions": ["康軒", "南一", "翰林"],  // 這個內容在哪些版本出現；"共通" 或省略＝所有版本都有
      // 若同一題在不同版本屬不同冊次，改用 terms 對照表（與 term 擇一）：
      // "terms": { "康軒": "6-1", "翰林": "5-1", "南一": "5-1" }
      "type": "choice",         // 題型，見下表
      "prompt": "題目文字",
      "options": ["A", "B", "C", "D"],
      "answer": 0,              // 正解在 options 的索引（從 0 開始）
      "tip": "作答後顯示的小提示（可省略）",
      "explain": "作答後顯示的解析"
    }
  ]
}
```

## 冊次（年級＋學期）與教科書版本

台灣國小／國中的教科書**都依同一份 108 課綱編寫**，所以康軒／南一／翰林／部編的**內容範圍相同**，
差別只在**同一主題排在幾年級上／下學期的第幾單元**。因此題庫用 `term` 記冊次、用 `versions` 記版本。

| term | 顯示 | 對應 |
|---|---|---|
| `4-1` / `4-2` | 四上 / 四下 | 國小四年級上／下學期 |
| `5-1` / `5-2` | 五上 / 五下 | 國小五年級上／下學期（預設 `5-1`） |
| `6-1` / `6-2` | 六上 / 六下 | 國小六年級上／下學期 |
| `7-1` / `7-2` | 七上 / 七下 | 國中七年級上／下學期 |
| `8-1`～`9-2` | 八上～九下 | 國中八、九年級（`grade` 填 7＝國中程度，用 `term` 區分冊次） |

- `versions` 可用值：`"康軒"`、`"南一"`、`"翰林"`、`"何嘉仁"`、`"佳音"`、`"共通"`（或整欄省略＝共通）。
- `term` 記的是**教科書實際把這個內容放在哪一冊**，可能與題庫的 `grade`（程度）標籤不同年級
  （例如「三角形內角和」課綱編在五上，但這題在遊戲裡是給小四練的），所以驗證器只檢查 term 是不是合法冊次。
- 有些內容在**不同版本屬於不同冊次**，就用 `terms`：例如「水溶液酸鹼」在康軒是六上、翰林與南一是五上，
  寫成 `"terms": {"康軒": "6-1", "翰林": "5-1", "南一": "5-1"}`。此時 `versions` 由 `terms` 的鍵決定。
- 學院頁可以切「**📶 冊次**（8 個）＋**📚 版本**（全部／康軒／南一／翰林）」，只從符合的題目抽題；
  題數不足 `roundSize` 時按鈕變灰。選擇記在 `localStorage`（`meowdoku.quizTerm`、`meowdoku.quizPublisher`）。
- 抽題會**依序退回**：指定冊次＋版本 → 同年級 → 全冊，確保永遠出得了題。
- `node tests/quiz.test.mjs` 會檢查：每個冊次都有 ≥ `roundSize` 題、三個版本在該冊次都有題、
  「標了 versions 的題目會被其他版本排除」。

## 各版本對照單元（`quizzes/units.json`）

學院頁選了版本之後，下方會列出**該版本在該冊次的單元清單**（例如「康軒 五上：1 多位小數 /
2 因數與公因數 / 3 倍數與公倍數 …」），讓小朋友對得上課本。

```jsonc
{
  "version": "114學年度",           // 資料年度（各校課程計畫的學年度）
  "subjects": {
    "math": {
      "name": "數學",
      "sources": ["https://…"],     // 每筆資料的來源網址（必填，禁止憑印象填）
      "units": [
        { "publisher": "康軒", "term": "5-1", "unit_no": 1, "unit_name": "多位小數", "sub_units": ["…"] }
      ]
    }
  }
}
```

**填寫原則**：單元名稱一律以可查證的公開資料（出版商目錄、各校課程計畫 PDF）為準，
查不到就留白（前端會顯示「還沒有可查證的對照資料」），**不要用印象補**。

## 程度（年級）

每題都要標 `grade`，學院頁右上／上方的「📶 測驗程度」可切換，抽題只從選定程度的題目抽。

| grade | 顯示 | 對應 |
|---|---|---|
| 4 | 小四 | 國小四年級 |
| 5 | 小五 | 國小五年級（預設） |
| 6 | 小六 | 國小六年級 |
| 7 | 國中 | 國中（七年級以上） |

- **每個程度至少要有 `roundSize` 題**，否則該程度的按鈕會變灰（`node tests/quiz.test.mjs` 會擋）。
- 程度會影響獎勵：金幣與能力值乘上倍率 小四 ×0.85 / 小五 ×1 / 小六 ×1.15 / 國中 ×1.3，
  體力消耗也隨之提高（`js/quiz.js` 的 `GRADE_REWARD`）。
- 題目請按實際課程進度寫（108 課綱該年級會學到的內容），不要用超綱題。
- 切換程度存在 `localStorage` 的 `meowdoku.quizGrade`。

## 題型

| type | 專屬欄位 | 判定 |
|---|---|---|
| `choice` | `options`：2～4 個不重複字串（畫面標示 A～D）；`answer`：正解索引 | 選到 `answer` 即正確 |

新增題型：在 `js/quiz.js` 的 `QUESTION_TYPES` 加 `validate`／`isCorrect`，
再在 `js/academy.js` 的 `renderQuizQuestion` 加該題型的作答畫面。

新增學科：除了題庫檔，`js/academy.js` 的能力象限會自動列出所有學科；
合格／滿分的金幣、屬性與掉落物在 `calculateQuizResult` 統一計算。
